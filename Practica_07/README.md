# 🚀 Práctica 07: Diagrama de Secuencia de Pantallas (Sketches)

## 🎮 Cowsmo: Space Rescue

### 📌 Descripción

Esta práctica consiste en diseñar un diagrama de secuencia de pantallas (*sketches*) para una aplicación relacionada con el videojuego **Cowsmo: Space Rescue**, un videojuego de plataformas 2.5D enfocado en la limpieza, el reciclaje, el rescate de personajes y la restauración ambiental.

El proyecto representa la navegación entre las diferentes pantallas de la plataforma, considerando dos roles de usuario: **Jugador y Administrador**. Además, organiza las interfaces correspondientes a las diferentes plataformas del proyecto: aplicación móvil, PWA, App Flutter y videojuego Unity.

## 🎯 Objetivo

Diseñar un diagrama interactivo de navegación que permita visualizar las pantallas de la plataforma, sus funcionalidades, los roles de usuario y las conexiones entre las diferentes secciones del proyecto.

## 🧩 Roles de usuario

- **Jugador:** Explora los planetas, selecciona niveles, recolecta residuos, recicla materiales, supera obstáculos, rescata personajes y consulta sus resultados y logros.
- **Administrador:** Gestiona los niveles, configura las misiones, administra las recompensas y consulta las estadísticas del videojuego.

## 🖥️ Plataformas del proyecto

El diagrama contempla las siguientes secciones:

- **Aplicación móvil:** Interfaz orientada a dispositivos móviles para consultar el progreso, las misiones y los logros.
- **PWA:** Aplicación web progresiva para explorar contenido, consultar personajes y visualizar el ranking.
- **App Flutter:** Interfaces móviles para consultar misiones, perfil, progreso y recompensas.
- **Videojuego Unity:** Experiencia principal de Cowsmo: Space Rescue, con exploración 2.5D, reciclaje, combate, rescate y restauración ambiental.

## 🗺️ Diagrama de navegación

El proyecto incluye un mapa general con miniaturas de las pantallas, conexiones de navegación y vistas ampliadas de los sketches seleccionados.

Las pantallas se organizan según su plataforma y funcionalidad, permitiendo identificar los recorridos principales de cada rol.

## 🛠️ Herramientas

- Archify para la generación del diagrama y los sketches.
- HTML para la visualización del proyecto interactivo.
- Diseño UX/UI para la organización de las pantallas y los flujos de navegación.

## ✅ Conclusión

La elaboración del diagrama de secuencia de pantallas permite comprender cómo se organiza la experiencia de usuario de Cowsmo: Space Rescue y cómo se relacionan sus diferentes interfaces.

La separación por roles y plataformas facilita la identificación de las funcionalidades principales y sirve como base para el diseño y desarrollo de la aplicación y del videojuego.
